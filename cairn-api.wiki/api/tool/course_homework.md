# 课程作业

所有接口均要求登录，只读取当前 Cairn 用户自己的绑定和快照。正式实现不使用固定用户 ID。

## 列表

`GET /api/v1/tool/course-homework/list`

| Query | 默认 | 说明 |
|---|---|---|
| `course_id` | 空 | 平台课程 ID，最长 64 字节 |
| `status` | `todo` | `todo`（待处理和逾期未交）、`pending`、`overdue`、`submitted`、`upcoming`、`unknown`、`all` |
| `page` | 1 | 正整数 |
| `page_size` | 20 | 1–100 |

响应信封为 `{ "code": 0, "data": { ... } }`，data 字段：

- `bound`：是否已有 MIS 绑定；未绑定时正常返回空列表，页面展开绑定表单。
- `student_id`：当前绑定的脱敏学号，未绑定时为空字符串。
- `has_snapshot`、`term_code`：当前绑定版本是否有同步记录及其最近学期。
- `last_success_at`：最近一次全部课程成功同步的时间，未完整成功时为 null。
- `courses`：课程 ID、名称、最近尝试/成功时间、同步错误。
- `counts`：五种作业状态的全部课程计数，不受当前筛选或分页影响。
- `items`：内部 ID、课程、标题、开放/截止/提交时间、平台原始提交状态 `submission`、页面分类 `status`、批改信息 `grading`。
- `total`、`page`、`page_size`：筛选后的分页数据。

列表只读快照，不触发登录或同步。排序按待处理、逾期、已提交、未开始、未知分组，同组按截止时间排序，无截止时间的置后。时间为带 `+08:00` 偏移的 RFC 3339；截止时刻相等即已截止。

## 刷新

`POST /api/v1/tool/course-homework/sync`，Body 必须是空对象 `{}`，不接受用户 ID、课程范围或上游 URL。

读取当前用户 MIS 凭据，经模块 28 建立课程平台会话，读取当前学期、全部课程及各门课全部作业分页。同一用户重复同步共享正在执行的结果；用户之间会话独立。上游工作最长 22 秒，总体保留至多 26 秒记录结果（在正常 30 秒 API 超时内）。

```json
{
  "code":0,
  "data":{
    "status":"partial",
    "succeeded":8,
    "failed":1,
    "term_code":"2026202701",
    "last_success_at":null,
    "courses":[]
  }
}
```

`status` 为 `success`、`partial`、`failed`。上例 `courses` 实际会包含每门课程的结果。课程全部分页读取成功后才在一个事务内更新该课程；失败保留旧数据。上游 `STATUS: "2"` 是正常空结果，成功空列表会清空对应课程。同步不执行作业提交，也不继承教室凌晨定时任务。

错误：未绑定 404；MIS 登录被拒绝 401；绑定已变更 400；当前学期或课程列表无法读取、数据库失败 500。部分/全部课程抓取失败通过 200 响应的 `status` 和逐课程 `error` 表达，不能解释为没有作业。

## 详情

`GET /api/v1/tool/course-homework/get?id=<内部ID>`。

先按当前用户及当前绑定版本查找内部记录，不允许用别人的 ID 读取；不存在返回 404。读取平台详情，返回 `item`、纯文本 `content`、`attachments: [{"name":"附件名称"}]`。附件 URL、会话令牌、教师内部标识不会返回。

上游详情失败时仍返回缓存正文和 `warning`，附件标明暂不可用。正文清除脚本与样式并转为安全文本，保留段落换行；前端使用文本插值，不使用 `v-html`。

## 状态

“已提交”独立于截止时间。未提交/被打回且尚未开放为 `upcoming`，已开放未截止为 `pending`，达到截止时间为 `overdue`。未识别的原始状态为 `unknown`，不会推断为已完成。缺失截止时间正常显示“无截止时间”；无法解析的时间导致该课程本轮同步失败并保留旧快照。
