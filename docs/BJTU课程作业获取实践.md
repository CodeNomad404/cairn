# 从 MIS 到课程作业：按用户隔离的只读聚合

课程作业工具的目标不是替代学校平台，而是集中回答：当前学期还有什么作业没交，什么时候截止。

## 从 HAR 找接口，再验证新会话

HAR 中包含学期查询、课程列表、作业列表与作业详情。记录里的 sessionId 会失效，不能成为实现中的常量。完整流程是：MIS OAuth 登录 → 模块 28 → `/ve/s.shtml` → 有效脚本跳转 → 平台首页 → 动态 sessionId。入口中的旧脚本已被 HTML 注释包裹，解析时必须忽略；也不能把首页退出登录函数里的 location.href 当成自动跳转。

平台 AJAX 返回 HTTP 200 并不一定代表有数据，`STATUS: "2"` 是正常空列表；作业和课程都必须翻页。列表返回未提交、已提交以及未来才开放的作业，因此提交状态与时间状态需要分开。

## 一个绑定接口，共享认证能力

公共绑定只接收学号和密码，身份来自 Cairn 登录上下文。验证成功才更新已有凭据记录，并保留抢课工具的图鉴配置。MIS 认证方法独立于抢课次数统计和任务恢复，避免读作业触发另一项业务。

学校 Cookie 与课程平台令牌保留在服务端，并按 Cairn 用户隔离。换绑递增 binding_version；快照查询关联当前版本，同步事务对凭据行加共享锁并核对版本，防止旧账号正在执行的请求在换绑后重新发布旧数据。

## 事务的边界是一门课程

一门课的全部分页获取成功后，在事务内更新条目并删除已不在成功结果中的旧条目。失败不清空上次快照；只有确认的成功空列表才清空。使用 upsert 保留已有作业的内部 ID，避免一次刷新使页面详情链接全部失效。

Go 的 context 同时限制上游耗时和等待，另留短暂且有总截止时间的持久化窗口记录失败。参考：[Go 事务说明](https://go.dev/doc/database/execute-transactions)、[取消耗时操作](https://go.dev/doc/database/cancel-operations)。

## 展示需要比上游更明确

`00:00` 截止就是当天零点，不能显示成当天结束。未知状态保留原文，不假装已完成。正文来自外部 HTML，转为保留换行的纯文本后使用 Vue 文本插值，避免直接执行外部内容。参考：[Vue 安全建议](https://vuejs.org/guide/best-practices/security)。

实现验证覆盖：多用户隔离、登录失败不覆盖、图鉴配置保留、分页与空结果、会话重登、部分失败保留旧快照、换绑期间旧同步写入拦截，以及迁移的 up/down。
