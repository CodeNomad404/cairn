在线 JSON 格式化与校验

将 JSON 数据粘贴到上方输入框，工具会自动检查语法并以树形结构展示结果。你可以展开对象和数组查看层级，也可以复制格式化后的内容或导出 JSON 文件，适合检查接口响应、配置文件和日志数据。

如何使用

  1. 粘贴或输入需要处理的 JSON 数据。
  2. 等待自动格式化，或点击“格式化”立即检查。
  3. 在右侧查看树形结果，然后按需复制或导出。

数据会上传到服务器吗？

不会。JSON 的解析、校验、格式化、复制和导出都在当前浏览器中完成，输入内容不会发送到 Cairn 服务器。处理接口密钥等敏感数据时，仍建议先移除不需要展示的字段。

常见问题

为什么 JSON 校验失败？

常见原因包括缺少逗号或引号、对象键没有使用双引号、末尾存在多余逗号，或者字符串中包含未转义的换行符。

JSON 和 JavaScript 对象有什么区别？

JSON 是严格的数据交换格式：对象键和字符串必须使用双引号，不支持注释、函数、undefined，也不允许尾随逗号。
